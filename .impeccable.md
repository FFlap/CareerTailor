# Impeccable

## Design Context

### Users

People tailoring a generated resume or cover letter for a specific job, one document
at a time, in a session long enough to care about the details. They are editing, not
authoring from scratch: the model produced a draft, and this screen is where they
correct it, tighten it, and watch the PDF change. Control matters more than speed —
nothing should be hidden from them, and no edit should happen that they did not ask
for. Desktop, two panes, keyboard within reach.

### Brand Personality

Dense, minimal, functional, monotone. The document is the subject; the tooling is the
darkroom around it. Quiet enough that a page of text is the brightest thing on screen.
No decoration that does not carry information.

### Aesthetic Direction

A typesetter's work surface. Hairline rules instead of cards, generous rhythm between
groups and tight rhythm within them. Monotone: a single tinted-neutral ink ramp does
all the hierarchy work, so weight, rule, and space carry meaning instead of hue. One
accent — ink itself — for the primary action. Colour appears only where it is
semantic: an error is red because it is an error.

Type: **Public Sans** for the interface, drawn for dense civic forms, which is what
most of this product is. **Archivo** for headings, where a tighter grotesque gives
weight without decoration. Monospace is reserved for code — the Typst source and its
line numbers — and never used for labels, meta, or numbers, where it reads as costume
rather than information. Figures that sit in a column are `tabular-nums` instead.

Light-first: the preview is a white page, and a dark shell fighting a white document
is the wrong contrast to optimise. Dark stays fully usable for evening sessions.

Anti-references: dashboard cards-within-cards, coloured category pills, gradient
anything, drop shadows used to fake depth, primary-blue buttons everywhere.

### Design Principles

1. **The page is the hero.** Chrome recedes; nothing in the editor should out-contrast
   the rendered document beside it.
2. **Hierarchy without hue.** Weight, rule, and space first. If something needs colour
   to be understood, the layout is wrong.
3. **Dense, not cramped.** Tight rows inside a group, real air between groups. Rhythm
   comes from varying the gap, not from padding everything equally.
4. **Disclosure, never concealment.** Sections collapse, but the interface always says
   what is inside one before it is opened, and state survives the session.
5. **No surprise writes.** Every action that changes the document is legible before it
   happens and reversible in intent afterwards.
